# Nike Sales Analysis using Python

## Overview
This project focuses on cleaning and analyzing a messy Nike sales dataset using Python. The goal was to practice real-world data cleaning and extract useful business insights with Pandas.

I had earlier analyzed this same dataset in Excel. This version focuses more on the data cleaning process and analysis using code.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
- Source: Nike Sales Uncleaned Dataset (Kaggle)
- Original issues: Missing values, inconsistent region names, incorrect data types, etc.

## What I Did
- Handled missing values in Units_Sold, MRP, Discount, Size, and Order_Date
- Standardised inconsistent city names in the Region column
- Performed exploratory data analysis using groupby and pivot tables
- Created basic visualisations for revenue by gender, channel, and top products

## Key Insights
- Men generated the highest total revenue, followed by Women and Kids
- Online channel performed better than Retail overall
- LeBron 20 was the top product by revenue
- Women showed a much stronger preference for Online shopping compared to Men
